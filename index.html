Using it each week

  1. Format the section in the Google Doc the way you want it, links and all.
  2. Copy that section, click the box above and paste.
  3. Click Copy cleaned text, click into the matching box in the Pardot template and press Ctrl + V.
  4. Repeat for each section. Keep the meter in the green across all sections combined.
